# Teaching voice review

The copy pass covers all 140 existing classes:97 reviewed original-class welcome entries (45 Windows/AD/SQL/Azure/migration,40 Linux/RHEL/Wazuh,12 AlmaLinux desktop), plus 43 rewritten Nessus lessons and 108 step action sets. Ten new Azure maintenance lessons bring the primary curriculum to 150 classes.

Each original class now has an individually authored welcome, plain explanation of why, concrete preparation list, an exact first action and relevant reassurance. The learner-facing readers display this guidance instead of opening with a compact requirements inventory. Exact technical details remain available for reference. Existing commands, routes, screenshot associations and original instruction hashes were retained. All108 Nessus command strings are checked against a pre-copy-review hash contract; IDs, order, source URLs and quiz answers remain intact.

Nessus preparation lists spell out the practice VM and files, explain memory/disk/installer terms, and move website validation limitations to the instructor reference section. Every lesson has its own next-step context. Shared reader prompts and quiz feedback use a patient teaching voice. Technical terms are still taught rather than removed.

The existing hosted console also has split VMware/Windows/server-role pages. Their phase-specific welcomes start in the appropriate application and retain those routes. The GitHub source branch is based on the existing Nessus feature branch, preserving current main’s teaching/readability work without merging either PR.

This is a reviewed copy and preparation pass, not a claim that every older technical reference paragraph has been rewritten or every missing screenshot captured. Original instructions remain authoritative when exact values, commands and recovery limits matter. See the Azure review inventory for the new course’s real-image coverage and remaining captures.
